# Joint planning: learning notebooks

Working notes on cognitive hierarchy models and their reinforcement-learning
rewrites, building toward simulating behavior in a 2-person stag hunt.

- **CH equations + RL rewrites** -- equations from Camerer, Ho & Chong (2004),
  term by term, with RL rewrites.
- **Stag hunt simulation** -- interactive: payoffs, beliefs, softmax, and the
  level-by-level hierarchy. Runs Python in your browser, so the first load
  takes a few seconds.

These notebooks accompany the [annotated reading list](https://wasita.space/joint-planning-lit/).
